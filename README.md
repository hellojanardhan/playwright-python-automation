# 🎭 Playwright Python Notes

A structured collection of **Playwright with Python + PyTest notes** designed for:

* 📚 Learning Playwright step by step
* 🧠 Understanding core automation concepts
* 🎯 Preparing for **QA Automation / SDET interviews**

The notes progress from **basic setup → core concepts → advanced framework design**.

## Running the Python examples

The repository also includes runnable UI and API tests in `tests/` and
`apitesting/`. See [AUTOMATION_SETUP.md](AUTOMATION_SETUP.md) for setup and
test-running instructions.
